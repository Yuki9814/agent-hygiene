# Support

Use GitHub issues for reproducible bugs, false positives, rule proposals, and
documentation gaps. Search existing issues first and submit sanitized inputs.

- Scanner defect: use the bug report form.
- Suspected false positive: use the false-positive form and include the rule ID.
- New rule: use the rule proposal form and describe both risky and safe cases.
- Vulnerability or bypass: follow [SECURITY.md](SECURITY.md) instead of opening
  a public issue.

The project is maintained on a best-effort basis. There is no guaranteed
response time, private consulting channel, or security certification. General
questions should be narrow enough to become durable public documentation.
